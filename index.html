Set up a Call Mum Phone

  1. Connect the old phone or tablet to wifi. No SIM card is needed.
  2. Open the WifiPhone Lite link, or scan its QR code with the camera.
  3. Add it to the Home Screen. iPhone: Share, then Add to Home Screen. Android: menu, then Install app or Add to Home screen.
  4. Pair with Mum's phone: on Mum's phone, scan this phone's QR code (or type its CB number), then save Mum here in Call Mum.
  5. Lock it to this app only. Android: Settings, Security, App pinning (Screen pinning). iPhone or iPad: Settings, Accessibility, Guided Access, then triple-click the side or home button to start.
  6. Keep it on the charger. The screen stays on while the app is open.

Works over wifi or a data eSIM. It calls only other Coffeebreak WifiPhone users. The 000 button uses the phone's own emergency calling, which works on a phone with no SIM only if that phone supports emergency calls without a SIM.
